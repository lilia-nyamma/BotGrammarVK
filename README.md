# VK English Grammar Bot — стартовый проект

Учебный VK-бот:
уровень → грамматическая тема → краткое правило → 3 упражнения → проверка 15 ответов → короткий разбор ошибок.

## Что внутри

- `main.py` — логика бота.
- `content.json` — грамматические темы, правила и упражнения.
- `requirements.txt` — библиотека VKBottle.
- `.gitignore` — не даёт случайно загрузить секреты.

В демонстрационной версии есть по одной теме для уровней A2, B1 и B2.
У каждой темы — 3 упражнения по 15 вопросов.

## Как запустить локально

Нужен Python 3.10+.

Установите зависимости:

```bash
pip install -r requirements.txt
```

Задайте переменную окружения `VK_TOKEN`.

Windows PowerShell:

```powershell
$env:VK_TOKEN="ВАШ_ТОКЕН"
python main.py
```

macOS/Linux:

```bash
export VK_TOKEN="ВАШ_ТОКЕН"
python main.py
```

Напишите сообществу VK: `Начать`.

## Как загрузить на GitHub

Создайте новый репозиторий и загрузите туда все файлы проекта.
Не добавляйте токен VK в код и не загружайте `.env`.

## Как запустить на Bothost

1. Создайте нового бота из Git-репозитория.
2. Укажите URL репозитория GitHub и ветку `main`.
3. Главный файл: `main.py`.
4. Добавьте переменную окружения:
   - имя: `VK_TOKEN`
   - значение: токен сообщества VK
5. Запустите/перезапустите деплой.

## Как добавлять новые темы

Откройте `content.json`.

Структура:

```json
{
  "A2": {
    "Название темы": {
      "rule": "Короткое правило",
      "exercises": [
        {
          "title": "Название упражнения",
          "questions": [
            {
              "question": "Вопрос",
              "options": ["вариант A", "вариант B", "вариант C"],
              "answer": "A",
              "tip": "Короткое объяснение ошибки"
            }
          ]
        }
      ]
    }
  }
}
```

Для каждой темы должно быть ровно 3 упражнения, а в каждом упражнении — 15 вопросов.

## Важное ограничение первой версии

Состояние пользователя хранится в оперативной памяти.
Если бот перезапустится, пользователь просто снова выберет уровень.
Когда понадобится сохранять прогресс и статистику, можно добавить SQLite в `/app/data`.
